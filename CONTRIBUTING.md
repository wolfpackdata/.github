# Contributing — temporary inheritance probe

**This file is a temporary probe and is removed in the next PR.** It exists for a few minutes
only, to prove that GitHub actually serves this repository's default community health files to
the rest of the `wolfpackdata` organization — and, specifically, that it serves them from this
repository's **`develop`** default branch.

Why a probe was needed: every one of the org's 36 repositories already carries its own
`.github/ISSUE_TEMPLATE/` and PR template, and a repository's own template shadows the org
default, so inheritance of the *templates* cannot be observed anywhere yet. `CONTRIBUTING.md`
is the one default community health file no repository in the org has, which makes it the only
observable signal available today.

Real contribution rules live in the Wolfpack GitHub SOP:
<https://github.com/wolfpackdata/wp-github-sop>.
